## 逐条输出

### 刑案-混合

> 一段典型的讯问笔录片段，七类敏感信息混在一句里

```
被告人[当事人1]，男，[日期1]出生，身份证号[身份证1]，手机[手机号1]，[地址1]。[日期2]通过尾号[银行卡1]的银行卡向[当事人2]转账[金额1]。案号[案号1]。
```

### 校验位-拦截

> 尾号改一位后 Luhn 不通过，应不替换——宁可漏，不可错

```
涉案账户为6222 0202 0000 1234，开户行不详。
```

### 法条-零误杀

> 纯法条文本，不该有任何替换。这一条是误杀测试

```
《中华人民共和国劳动合同法》第八十七条规定，用人单位违反本法规定解除或者终止劳动合同的，应当依照本法第四十七条规定的经济补偿标准的二倍向劳动者支付赔偿金。
```

### 身份证-两人

> 同一段出现两个身份证，占位符要能区分

```
证人一身份证[身份证1]，证人二身份证[身份证2]，二人系同事。
```

### 姓名-无词表

> 不给词表时，靠线索词 + 姓氏表猜，置信度降到 0.6 需人工确认

```
被害人[当事人1]陈述，被告人[当事人2]于当日进入其住所。
```

### 联系方式-邮箱

> 邮箱与手机并列出现

```
如有异议请联系[手机号1]或发送至[邮箱1]。
```

### 金额-中文大写

> 阿拉伯数字金额 + 万元单位

```
被告人收受好处费共计[金额1]，另查明其名下存款[金额2]。
```

### 日期-不误吞

> 2024年3月15日必须整体命中，不能只吃 2024年3月1 而漏掉 5日

```
案发时间为[日期1]，报案时间为[日期2]。
```
